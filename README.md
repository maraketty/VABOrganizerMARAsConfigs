# VAB Organizer Configs for Modular Segmented SRBs

VAB Organizer configs for several mods that do not have native support nor pre-existing configurations on [CKAN](https://github.com/KSP-CKAN/CKAN).

## Dependencies (Required): 
- [Module Manager](https://github.com/KSP-ModularManagement/ModularManagement)
- [VAB Organizer](https://github.com/KSPModStewards/VABOrganizer)

## Recommended  (Optional):
- [Patch Manager](https://github.com/linuxgurugamer/PatchManager)

## Supported Mods:
- [Modular Segmented SRBs](https://github.com/linuxgurugamer/ModularSegmentedSRBs)
